 **一层由 Hugo 主题生成的自适应网格背景（Adaptive Grid Texture），之上叠加了一组分离式悬浮的液态玻璃胶囊导航组件（Detached Floating Liquid-Glass Pill Navigation），左右分组独立包裹，通过 `backdrop-filter` 实现背景模糊与深度分离，中间留白区域保留网格的完整可见性，形成材质与空间的双重层次对话。** 


# 角色设定
你是一名资深的创意前端工程师，精通现代 UI 设计、CSS 渲染以及 React/Tailwind CSS（或纯 HTML/CSS）开发。

# 任务目标
请为我生成一个单页网站的首屏（Hero Section）代码。要求将“极简的几何网格背景”与“分离式悬浮液态玻璃导航栏”完美结合，营造出高级的空间层次感与材质对比。

# 核心视觉需求与布局规范

## 1. 首屏背景（底层 L0）：自适应网格纹理 (Generative Grid Texture)
- **不使用**任何图片或视频背景。
- 使用纯 CSS（如 `repeating-linear-gradient`）或 SVG 生成一层极简的网格底纹。
- **视觉特征**：背景基调为浅色（如极浅的灰白或米白），网格线颜色略深于背景，保持低对比度、细腻、不抢眼。类似于工程坐标纸或蓝图，提供理性的结构秩序感。
- **交互**：背景固定（fixed），确保页面滚动时网格不动，增加沉浸感。

## 2. 顶部导航栏（顶层 L2）：分离式悬浮液态玻璃组件 (Detached Floating Liquid-Glass Navigation)
- **定位**：使用 `position: fixed` 悬浮在页面顶部，带有适度的左右和顶部边距（如 `top-4 inset-x-6`），宽度自适应但不超过全屏。
- **布局结构（核心）**：采用 `flex justify-between` 布局。导航栏**不是**一个连续的长条，而是**左右分离的两个独立胶囊（Pill）容器**。中间区域完全留空、透明，直接透出底层的网格背景。
- **左胶囊（品牌区）**：包含一个圆形头像/Logo 和站点名称，整体包裹在一个半透明的圆角胶囊内。
- **右胶囊（功能控制台）**：包含一组圆形图标按钮（如：搜索 🔍、音乐 🎵、主题 🎨、明暗 ☀️、菜单 ☰），整体包裹在另一个半透明圆角胶囊内。
- **材质实现（Glassmorphism / Liquid Glass）**：
  - 背景色：`rgba(255, 255, 255, 0.15)` 左右的半透明白。
  - 核心属性：`backdrop-filter: blur(16px) saturate(180%)`。
  - 边框与高光：极细的半透明白色边框 `border: 1px solid rgba(255,255,255,0.3)`，以及顶部的内侧高光 `box-shadow: inset 0 1px 0 rgba(255,255,255,0.4)`，模拟玻璃边缘的折射感。
  - 圆角：大圆角 `border-radius: 9999px`（胶囊形）。

## 3. 首屏内容区（中层 L1）
- 极简的居中文本排版。大标题（如“朝朝听雨”或品牌名），配以浅色的副标题。
- 文字层级位于网格背景之上（`z-index: 10`），但**低于**悬浮导航栏（`z-index: 50`）。

# 交互与动效要求 (Micro-interactions)
- **导航栏图标 Hover**：右侧胶囊内的圆形图标在鼠标悬停时，背景微微泛白（增加透明度），图标有轻微的缩放或旋转反馈，过渡动画需平滑（`transition: all 0.3s ease`）。
- **玻璃态呼吸感**：如果是暗色模式，半透明背景需自动调整为 `rgba(0, 0, 0, 0.2)` 等深色系玻璃。

# 响应式要求
- 移动端：左右胶囊可保持布局，但右侧图标组可适当精简（隐藏部分次级图标），或尺寸略微缩小。

请输出完整的 HTML 和内联/作用域 CSS 代码（或 Tailwind CSS 代码），确保代码可直接在浏览器中预览，并且所有的视觉效果参数（如模糊度、边框透明度）需精准调校，以达到极致的“液态玻璃”质感。
